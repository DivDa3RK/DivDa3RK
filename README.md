## 🔬 Featured Project In Depth: DarkBruter

<div align="center">

<img src="https://img.shields.io/badge/Type-Web_Security_Scanner-ff00ff?style=for-the-badge" alt="Type" />

</div>

### 📋 Overview
**DarkBruter** is an advanced async web security scanner designed for modern penetration testing workflows.

### ✨ Key Features
- 🔍 **SQL Injection Detection** - Advanced blind, time-based, and error-based SQLi detection
- 💉 **XSS Scanner** - DOM-based, reflected, and stored XSS identification  
- ⚡ **Async Scanning Engine** - High-performance concurrent scanning with aiohttp
- 🛡️ **Proxy & Tor Support** - Anonymous scanning through SOCKS5/HTTP proxies
- 📊 **Smart Reporting** - JSON/HTML/PDF report generation with severity ratings
